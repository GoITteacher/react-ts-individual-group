# ЗАДАЧІ USE STATE

## ПРОСТІ ЗАДАЧІ

1. Створи компонент Counter. Цей компонент повинен відображати поточне число та дві кнопки: Increase і Decrease. Створи стан, у якому буде зберігатись значення лічильника. При кліку на кнопку Increase число має збільшуватись, а при кліку на Decrease — зменшуватись.

2. Створи компонент ThemeSwitcher. У компоненті повинна бути кнопка для перемикання теми між Light mode та Dark mode. Також змінюй фон і колір тексту залежно від активної теми.

3. Створи компонент MessageToggle. Компонент повинен містити кнопку Show message. Після натискання має з’являтись текстове повідомлення. Якщо натиснути кнопку ще раз — повідомлення повинно зникнути.

4. Створи компонент LikeButton. На екрані повинно відображатись сердечко 🤍. При кліку на нього сердечко повинно змінюватись на ❤️. Повторний клік має повертати попередній стан.

5. Створи компонент Lamp. Компонент повинен показувати текст Light OFF. Додай кнопку Toggle. При натисканні текст має змінюватись на Light ON, а при повторному натисканні — назад.

6. Створи компонент TextSwitcher. На екрані спочатку повинен відображатись текст Hello. При кліку на кнопку текст має змінюватись на Goodbye.

7. Створи компонент PasswordToggle. Додай поле для вводу пароля та кнопку Show password. При натисканні пароль має ставати видимим. Повторне натискання повинно знову приховувати пароль.

8. Створи компонент OnlineStatus. Компонент повинен показувати статус користувача: Online. Додай кнопку, яка буде змінювати статус на Offline і назад.

9. Створи компонент Temperature. На екрані повинна відображатись температура, наприклад 20°C. Додай дві кнопки: одна збільшує температуру, інша — зменшує.

10. Створи компонент EmojiSwitcher. Спочатку має відображатись emoji 🙂. При кліку на кнопку emoji повинно змінюватись на 😎. Повторний клік повертає попередній emoji.

11. Створи компонент AgeChecker. Додай поле для вводу віку. Якщо користувач вводить число більше 18 — відображай текст Adult. Якщо менше або дорівнює 18 — показуй Child.

12. Створи компонент VisibilityBlock. На сторінці повинен бути кольоровий блок і кнопка Hide block. При натисканні блок має зникати, а текст кнопки змінюватись на Show block.

13. Створи компонент MiniCounter. Компонент повинен показувати число. Якщо значення стає більшим за 10 — додатково показуй повідомлення Too much!.

14. Створи компонент MusicPlayer. На екрані повинен бути текст Music paused. Додай кнопку, яка буде змінювати статус на Music playing і назад.

15. Створи компонент Notification. Спочатку повідомлення не повинно відображатись. Після натискання на кнопку Show notification має з’являтись невелике повідомлення з текстом New message received.

## CЕРЕДНІ ЗАДАЧІ

1. Створи компонент для підрахунку відгуків. У компоненті має бути три окремих стани:

- кількість позитивних відгуків
- кількість нейтральних відгуків
- кількість негативних відгуків

На екрані повинна відображатись кількість кожного типу відгуків. Також додай три кнопки:

- Like
- Neutral
- Dislike

При натисканні на відповідну кнопку кількість відгуків цього типу повинна збільшуватись.

⸻

2. Створи компонент профілю користувача. У компоненті має бути:

- ім’я користувача
- статус онлайн
- кількість підписників

Створи окремий стан для кожного значення. Додай кнопку для зміни статусу між Online та Offline, а також кнопки для збільшення і зменшення кількості підписників.

⸻

3. Створи компонент кошика товару. У компоненті повинно відображатись:

- назва товару
- кількість товарів
- загальна ціна

Створи окремий стан для кількості товарів і для загальної ціни. Додай кнопки Add item та Remove item. При додаванні товару кількість і загальна ціна повинні збільшуватись.

⸻

4. Створи компонент музичного плеєра. У компоненті має бути:

- назва пісні
- статус плеєра (Playing або Paused)
- гучність

Створи окремий стан для статусу плеєра та для гучності. Додай кнопку для запуску/паузи музики і кнопки для збільшення та зменшення гучності.

⸻

5. Створи компонент оцінки фільму. Користувач повинен мати можливість:

- поставити лайк
- поставити дизлайк
- додати фільм у вибране

Для кожної дії створи окремий стан. Компонент повинен показувати поточний стан кожної дії.

⸻

6. Створи компонент налаштувань сайту. У компоненті повинні бути:

- перемикач темної теми
- перемикач сповіщень
- перемикач звуку

Для кожного налаштування створи окремий стан. На екрані повинно відображатись, які функції зараз увімкнені.

⸻

7. Створи компонент гри. У компоненті має бути:

- кількість життів
- кількість монет
- рівень гравця

Створи окремий стан для кожного значення. Додай кнопки для збільшення монет, втрати життя та підвищення рівня.

⸻

8. Створи компонент банківського рахунку. У компоненті повинно відображатись:

- баланс
- кількість виконаних операцій
- статус картки (Active або Blocked)

Створи окремий стан для кожного значення. Додай кнопки для поповнення балансу, зняття коштів та блокування картки.

⸻

9. Створи компонент замовлення їжі. У компоненті має бути:

- кількість піц
- кількість напоїв
- загальна сума замовлення

Створи окремий стан для кожного значення. Додай кнопки для додавання піци та напоїв. Загальна сума повинна автоматично змінюватись.

⸻

10. Створи компонент статистики навчання. У компоненті повинно відображатись:

- кількість завершених уроків
- кількість помилок
- кількість правильних відповідей

Створи окремий стан для кожного значення. Додай кнопки для оновлення кожного показника.
