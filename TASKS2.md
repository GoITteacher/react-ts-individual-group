ЗАДАЧІ USE STATE — ВАРІАНТ 2

ПРОСТІ ЗАДАЧІ

1. Створи компонент ColorSwitcher. На екрані повинен бути квадрат. Додай кнопку Change color. При натисканні колір квадрата має змінюватись між blue та green.

2. Створи компонент GreetingCard. Спочатку компонент повинен показувати текст Good morning. Після натискання на кнопку текст має змінюватись на Good evening.

3. Створи компонент VolumeControl. На екрані повинно відображатись число гучності. Додай кнопки Volume + та Volume -. Значення має змінюватись при натисканні.

4. Створи компонент LoginStatus. Спочатку користувач повинен мати статус Logged out. Після натискання на кнопку статус має змінюватись на Logged in.

5. Створи компонент FontSizeChanger. На екрані має бути текст. Додай кнопки Increase font та Decrease font. Розмір тексту повинен змінюватись.

6. Створи компонент EmojiReaction. Спочатку повинен відображатись emoji 👍. При натисканні на кнопку emoji має змінюватись на 👎.

7. Створи компонент BorderToggle. На сторінці повинен бути блок без рамки. Після натискання на кнопку рамка повинна з’являтись.
8. Створи компонент CitySwitcher. На екрані повинен показуватись текст Prague. При натисканні на кнопку місто має змінюватись на London.
9. Створи компонент TimerValue. Компонент повинен показувати число секунд. Додай кнопки Add second та Remove second.
10. Створи компонент CardFlip. Спочатку повинна показуватись сторона Front side. Після натискання на кнопку має показуватись Back side.
11. Створи компонент TextColor. На екрані повинен бути текст чорного кольору. Додай кнопку, яка буде змінювати колір тексту на червоний.
12. Створи компонент ButtonDisable. На сторінці повинна бути кнопка Submit. Після натискання кнопка має ставати неактивною.
13. Створи компонент CoffeeSize. На екрані повинно показуватись значення Small coffee. Після натискання на кнопку текст має змінюватись на Large coffee.
14. Створи компонент ProgressBar. Компонент повинен показувати число прогресу у відсотках. Додай кнопку Increase progress. Значення повинно збільшуватись.
15. Створи компонент FavoriteStar. На екрані повинна бути зірочка ☆. При натисканні вона має змінюватись на ★.

CЕРЕДНІ ЗАДАЧІ

1. Створи компонент профілю гри. У компоненті має бути:

- ім’я персонажа
- кількість енергії
- статус персонажа (Alive або Dead)

Створи окремий стан для кожного значення. Додай кнопки для збільшення енергії та зміни статусу персонажа.

⸻

2. Створи компонент бронювання квитків. У компоненті повинно відображатись:

⸻

Створи окремий стан для кожного значення. Додай кнопки для додавання товарів та зміни статусу доставки.

- статус читання (Reading або Break)

Створи окремий стан для кожного значення. Додай кнопки для оновлення показників.

Створи окремий стан для кожного значення. Додай кнопки для збільшення підписників, переглядів та зміни статусу стріму.
